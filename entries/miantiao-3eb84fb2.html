面条（剔尖/拌痂吃咾擀痂的面）

原清洁稿标题（仅供核对，不作词条名）：回回（155）

常见写法

剔尖拌痂吃咾擀痂的面痂连汤圪瘩拌佳汤拌家尖儿女拌介汤家抿加擦加拌掐汤抿荐借借剔皆擀皆皆擀秸秸剔节流节迸节抿尖尖抿浆儿拌浆汤擦加加拌加加加拌积不烂羹抿尖儿

各地记写

  • 《孝义俗语大观》
    写法：你说王八厮儿不好，油糕豆面家管饱
    面条
  • 《孝义县志（1992年版）》
    写法：拌痂吃咾擀痂的面 / 三十里地的馍馍二十里地的糕，十里地的豆面痂饿折腰
  • 《乡言研究》
    写法：痂
    面条
  • 《俗语解颐》
    写法：拌糘（疙瘩汤）吃了擀糘（面条）的面
  • 《汾阳俗语》
    写法：连汤圪瘩拌佳汤
  • 《汾阳方言研究》
    写法：拌家
    拌汤
  • 《汾阳话与普通话简编》
    写法：尖
    泛指各种面条，‘擀尖、抿尖、擦尖、剔尖’。（晋中有的地方读（ji）。剔尖有的叫拨鱼儿。）
  • 《平遥方言民俗语汇》
    写法：儿女拌介汤 / 剔尖
    旧时在合婚席上新人吃的带有四个小饺子的疙瘩汤；用铁铲切出的面条儿，长约二、三寸
  • 《介休方言志》
    写法：家
    面条儿
  • 《中阳县方言志》
    写法：抿加 / 擦加
    水煮河捞（小）；蒸着吃得扁河捞
  • 《临县方言志》
    写法：拌掐汤
    拌汤面
  • 《山西岚县方言》
    写法：抿荐
    黄豆面做的面条儿。先用筷子把黄豆面和好，在特制礤床上手握面团直接擦入沸水锅
  • 《祁县方言志》
    写法：借借
    条状面食总称
  • 《太谷方言志》
    写法：剔皆 / 擀皆皆
    一种面食；切面
  • 《清徐方言志》
    写法：擀秸秸
    面条儿
  • 《晋源方言研究》
    写法：剔尖
    白面拨鱼
  • 《小店方言研究》
    写法：剔节 / 流节 / 迸节
    剔尖，一种小麦粉煮制面食；一种小麦粉煮制面食；一种小麦粉煮制面食
  • 《太原方言词典》
    写法：抿尖尖
    一种面食，用特制的有许多小圆孔的抿槽抿成的高粱面条
  • 《娄烦方言研究》
    写法：抿浆儿 / 拌浆汤
    一种面食；面疙瘩汤
  • 《灵石方言研究》
    写法：擦加加 / 拌加 / 加加
    擦圪斗；疙瘩汤；面条
  • 《吉县方言志》
    写法：拌积
    拌汤
  • 《沁河流域民俗语汇：以端氏方言为例》
    写法：不烂羹
    拌汤。有小瓜不烂羹、汤面不烂羹、酸菜不烂羹等
  • 《神木方言研究》
    写法：抿尖儿
    一种短豆面条儿，用抿床礤制
