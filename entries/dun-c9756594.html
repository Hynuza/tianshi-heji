蹲（圪蹴/圪蹲）

原清洁稿标题（仅供核对，不作词条名）：回回（194）

常见写法

圪蹴圪蹲圪蹴下好汉不打圪纠纠圪蹴蹴圪纠跍蹲蹴趷蹴骨蹲咕蹲

各地记写

  • 《乡言研究》
    写法：圪蹴
    蹲
  • 《孝义俗语大观》
    写法：有钱儿的说的是气粗话，吓的穷厮儿圪纠下 / 好汉不打圪纠纠
    蹲；蹲下，指认输
  • 《孝义方言志》
    写法：圪蹴 / 圪蹴蹴
    蹲；蹲下，儿语：圪蹴蹴，逮不住
  • 《汾阳话与普通话简编》
    写法：咯踞（音纠）
    蹲
  • 《介休市志（1996年版）》
    写法：圪纠
    蹲
  • 《清徐方言志》
    写法：圪蹴
    蹲
  • 《太原方言词典》
    写法：圪蹴
    蹲：圪蹴下去，不要站着
  • 《阳曲方言志》
    写法：圪蹴下
    蹲下
  • 《代县方言研究》
    写法：圪蹴
    蹲
  • 《应县方言词汇》
    写法：圪蹴（jiōu）
    蹲下来。例你们欢欢圪蹴下，前头有查超载的哩
  • 《晋语•应州方言例释》
    写法：圪蹴 / 圪蹲
    蹲着；1.蹲着。2.停下等待：咱们先在这儿圪蹲一会儿，车很快就过啦
  • 《天镇方言研究》
    写法：圪蹴
    蹲
  • 《榆社方言研究》
    写法：圪蹴
    蹲
  • 《沁县方言志》
    写法：圪蹴下
    蹲下
  • 《沁河流域民俗语汇：以端氏方言为例》
    写法：圪蹲
    蹲
  • 《阳城方言》
    写法：跍蹲
    义同蹲（dūn）。例：噢俩人到一坨通有怎说的了，跍蹲在街门圪洞侃呱得一圪塔劲。｜见人胡胡（胡子）摸下巴，见人屙屎跍蹲下
  • 《夏县方言志》
    写法：蹴
    蹲
  • 《神木方言研究》
    写法：圪蹴 / 圪蹲
    蹲；蹲
  • 《陕北区域方言选释》
    写法：趷蹴
    蹲在地上：他于是趷蹴在路边，伸出两只手想烤一烤火。也说‘圪蹴’
  • 《宣化方言》
    写法：骨蹲
    蹲着，也叫‘圪蹴’
  • 《蔚州方言词萃》
    写法：咕蹲
    蹲。常用于比喻站得住脚。〔例〕这地方（村），可不好咕蹲哩
