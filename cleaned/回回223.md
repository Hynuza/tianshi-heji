# 回回（223）

## 方志与著作记写

- 《乡言研究》：写法「醪毛失七」；释义「醪毛：义务帮助。形容主动为别人帮忙，白尽义务。〔例〕兀家每天起来醪毛失七地，自家的事了顾不上做」
- 《平定话》：写法「落（lào）毛」；释义「无偿的为别人干活，做事。如说：‘我成天没明没夜累死累活的，也不知道这是给谁落毛咧。’」
- 《盂县方言词汇》：写法「落毛」；释义「无偿地给别人做事：给人落毛哩」
- 《忻州俗语志》：写法「烙毛」；释义「白干活儿：他一天儿和人烙毛」
- 《忻州方言词典》：写法「烙毛 / 烙毛猴」；释义「白干活儿：他一天儿（经常）和（给）人烙毛｜用你和伢（人家）烙毛哩；出于某种目的而为别人白干活儿的人（含斥责意）：𠰻狗（那人，詈语）是个烙毛猴，一有空（时间）就给领导受（干活儿）去啢」
- 《繁峙方言俗语汇编》：写法「落毛」；释义「即‘帮忙’（贬义）。也说‘白落毛’。如：他落毛的营生太多」
- 《应县方言研究》：写法「白烙毛」；释义「白帮忙」
- 《应县方言词汇》：写法「白烙毛 / 烙（lào）毛」；释义「白帮忙。例一天就那白烙毛；闲帮忙。例东家不让白烙毛，赏了咱一条烟」
- 《晋语•应州方言例释》：写法「白烙毛」；释义「做活没工钱；帮闲忙：不挣钱，就给尔白烙毛哩」
- 《内蒙古土默川方言赏析》：写法「捞毛 / 捞毛小子 / 捞毛货」；释义「原指在妓院打杂。方言中指白为别人干活而毫无报酬。（捞，发‘烙’音。捞毛，也作‘烙毛’）干活没工钱，捞毛跼（ju）瞎眼。成天起来那捞毛营生做不完；随叫随到，干活不挣钱，吃饭没工钱的人。那是个捞毛小子，谁叫做营生也行，不过，他有事，众人也都愿意帮他；经常自愿白给别人帮忙干活的人。那个捞毛货，每天去村长家做营生，也不知道想咋了」
- 《赤峰方言通释》：写法「落忙 / 落忙的」；释义「帮助别人打理事情（动词）。如：丈夫到邻居家落忙去了；帮助料理红白喜事的人（名词）。如：家里来了很多落忙的」
- 《海原方言词语汇释》：写法「捞毛」；释义「做无意义或价值不大的杂事。成天捞毛着没啥意思」
- 《关东方言词汇》：写法「劳忙的」；释义「指红白喜事来帮忙的人。〔例〕‘此刻，崔立荣着急呀，直劲催促那几个劳忙的’」
- 《品味延庆话》：写法「劳毛」；释义「即帮忙。用诙谐的口吻称帮忙。如，‘又给谁劳毛去啦？’‘又到哪儿劳毛去啦？’延庆人称不该帮的忙也帮为‘瞎劳毛’。疑出自‘捞毛’，费了很大力，‘捞’回的是‘毛’」
