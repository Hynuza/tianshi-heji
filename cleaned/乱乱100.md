# 乱乱（100）

来源文件: `[2024-02-26-0600]乱乱100.html`

## 方志与著作记写

- 《晋源方言》：写法「虚鼻圪喳 / 虚鼻壳壳」；释义「沉不住气，受一点苦就叫苦连天；形容人过于娇嫩，吃不得一点苦」
- 《盂县方言词汇》：写法「虚逼 / 虚逼淡话 / 虚逼寡嘴」；释义「说大话或说超过自身实际的话：你不要虚逼，到时候要见实的哩；说空话或说不着边际和不解决问题的话：他尽说了些虚逼淡话；说空话或淡而无味的话：那人是个虚逼寡嘴，说得好，做得差」
- 《代县方言大全》：写法「虚比」；释义「大惊小怪。例：这么小的个虫子就吓得他虚比乱叫」
- 《繁峙方言俗语汇编》：写法「虚比 / 大虚比」；释义「形容言过其实，或过分夸大其词。如：这么点小事，不用虚比；名词，指习惯故弄玄虚，夸大其词的人。如：那人是个大虚比」
- 《应县方言研究》：写法「虚屄 / 可虚比了半天，拢共儿才来了六个人」；释义「小题大作；偶因小的意外而失态；虚了半天，总共才来了六个人」
- 《应县方言词汇》：写法「虚屄」；释义「小题大做；偶因小的意外而失态。例戳破点皮，就虚屄成那」
- 《陇右方言词语研究》：写法「虚脾 / 虚脾流水」；释义「虚情假意，巧言应付。例一：你常说要请大家咋一顿哩，但谁连一个酸梨儿也没吃到过你的，你再休虚脾了。例二：兀个人说话虚脾流水的，谁信他哩；说虚编谎的状态。如‘兀个人时常虚脾流水地编谎着哩。’虚脾，说虚编谎、虚情假意」
- 《元剧俗语方言例释》：写法「虚脾」；释义「虚情，假意」
- 《宋元语言词典》：写法「虚脾」；释义「虚情假意，亦指虚假。向滈」
