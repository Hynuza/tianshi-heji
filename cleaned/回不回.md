# 回不回

## 方志与著作记写

- 《乡言研究》：写法「见不得」；释义「讨厌」
- 《金圪垯说古老精深的临县话》：写法「厮挚不得，厮离不得（互相见不得，互相离不得） / 卖好面的挚不得卖石灰的（比喻同行相轻）」
- 《兴县方言研究》：写法「那号子人唤（和）谁也折不得（相处不来）」
- 《太原方言词典》：写法「见不得」；释义「看不惯；不愿看见：我见不得懒汉」
- 《偏关方言》：写法「见不得 / 着不得」；释义「不喜欢◆我贵贱见不得你价家的人；合不来◆他们两家着不得，可能吵架了」
- 《汾西方言研究》：写法「见不得」；释义「看不惯、看不上、看着不顺眼」
- 《卧虎山麓方言》：写法「挂不得」；释义「讨厌，例：我就挂不得他」
- 《万荣方言志》：写法「卖石灰的刮不得卖面的 / 烟也罢，茶也罢，我都不挂」；释义「嫉妒；烟也好，茶也好，我都不喜欢」
- 《内蒙古土默川方言赏析》：写法「见不得」；释义「讨厌；容不得。大河畔上瞎老多，家大人多见不得我。他那个人就是看人头儿下菜碟子，溜有的敬富的，死见不得穷人」
- 《陕北区域方言选释》：写法「见不得 / 折不得 / 着不得」；释义「看不惯；不喜欢：不知道咋兰，小梅一满见不得那；见不得；不需要：我可折不得那些毛天鬼神的人；讨厌的意思：前锅底烧柴后锅底炭，我多少着不得那死囚汉｜着不得下雨，哎哟，着不得刮风，刮风下雨不得安身｜有心送哥两颗梨，滚身子着不得凉东西｜我死着不得赌博的人」
- 《绥德方言调查研究》：写法「着得 / 着不得」；释义「容得下，能接收；容不下，不能接收」
