## 方志与著作记写

- 《孝义俗语大观》：写法「当家三年，惹得狗儿也不戴见」；释义「喜欢」
- 《太原方言词典》：写法「待见」；释义「❶疼爱：老太太最待见他咧❷喜欢：我待见蓝色儿，不待见黄的」
- 《山西东部方言研究（左权卷）》：写法「待听」；释义「指喜欢听」
- 《寿阳方言志》：写法「戴见」；释义「喜爱」
- 《平定方言研究》：写法「待见 / 待吃」；释义「喜欢；指人想吃或爱吃」
- 《平定话》：写法「爱见 / 不待 / 得（dié）见」；释义「打心眼里喜欢；喜爱……爱，方言读作diē；不想；不愿意。如说‘不待动’、‘不待求人’等；喜爱；看得起。常作‘爱见’……也作‘待见’」
- 《盂县方言研究》：写法「‘待’是一个表示心理活动的动词，表示‘喜欢’或‘愿意’等意义，在口语中所表达的主观意愿十分强烈 / 待 / 待见」；释义「喜欢做，愿意做；喜欢」
- 《盂县方言词汇》：写法「爱见 / 不待见 / 不待听 / 待见 / 怠答不理」；释义「喜欢，她爱见那件衣服；不愿意见到；不高兴：为这点小事还惹了个不待见；➊不相信：不待听，他不是说别人坏话的人。➋不能听或不愿听：他说了些不待听的话。听，读梯；长得喜人：小姑娘长得可待见哩；轻慢对待：和他说，人家怠答不理的」
- 《忻州方言词典》：写法「待见」；释义「喜欢，喜爱：我就待见和他告诉（交谈）」
- 《代县方言大全》：写法「待见」；释义「喜欢。例：我特别待见那件红色上衣」
- 《朔州方言研究（右玉卷）》：写法「‘待’表示‘愿意’。如：（166）你待去不（你愿意去吗？）（167）我不待去了，你去哇（我懒得去了，你去吧。）」
- 《应县方言研究》：写法「待见」；释义「喜爱」
- 《晋语•应州方言例释》：写法「不怠」；释义「懒得做：懒得啥也不怠做」
- 《沁县方言志》：写法「戴见」；释义「喜爱」
- 《武乡方言志》：写法「待见」；释义「喜欢」
- 《壶关方言词汇集》：写法「爱见」；释义「喜爱，喜欢：这个小孩又聪明、又勤快，很招人爱见」
- 《山西东部方言研究（壶关卷）》：写法「待见」；释义「让人喜欢」
- 《陵川方言志》：写法「戴见」；释义「喜爱」
- 《上党地区方言研究（阳城卷）》：写法「好话说多少，人家贵贱不待听」
- 《内蒙古土默川方言赏析》：写法「喜见」；释义「喜欢。茅庵房房院墙低，哈巴狗嘀啖是喜见你」
