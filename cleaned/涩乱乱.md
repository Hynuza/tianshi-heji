# 涩乱乱

来源文件: `[2024-08-03-0600]涩乱乱.html`

## 方志与著作记写

- 《太原方言词典》：写法「涩巴巴」；释义「涩得使人不舒服：柿子涩巴巴的，有甚吃头」
- 《盂县方言词汇》：写法「涩巴裂疥 / 涩巴溜秋」；释义「物体不光滑：这把锹把涩巴裂疥的不好使。也说涩巴裂且；不光滑，很难看的样子：这堵墙涩巴溜秋的该重抹了」
- 《灵丘县方言词语解读》：写法「什疤拉崛的」；释义「其义也是形容很不光滑、很不平整」
- 《大同方言博览》：写法「涩列列」；释义「不滑润。‘这点儿小米熬出稀粥涩列列的不好喝。’」
- 《卧虎山麓方言》：写法「涩辣 / 涩巴 / 涩里巴拉」；释义「苦涩；同上；非常苦涩」
- 《阳城方言》：写法「涩圪巴巴 / 涩不拉拉」；释义「①形容不润滑；粗涩。例：握着父亲涩圪巴巴的大手，我的心里有一种说不出难受。②形容味道苦涩。例：柿没漤好，涩圪巴巴的真难吃。③形容难为情；羞涩。例：求人办事，你不多少撖点东西，涩圪巴巴的不好意思；同‘涩圪巴巴’①。粗涩。镢把还没使出来，还是涩不拉拉的，休着把手磨烂了，使动戴上手帽」
- 《方言漫笔晋南卷》：写法「沙疤」；释义「物体表面粗糙、不光滑。又引伸为味涩。如：‘这柿子没漤好，吃上还有点沙疤。’」
- 《敖汉方言例释》：写法「奢巴」；释义「涩，口感差。［举例］忒奢巴了，这李子根本没熟」
- 《神木方言研究》：写法「涩练练」；释义「①（物体表面）非常粗糙的样子；②（食物在嘴里）很不爽口的感觉」
- 《元氏方言志》：写法「湿吧」；释义「物体表面粗糙不光滑」
- 《宣化方言》：写法「涩将骨略 / 涩疤圪劣」；释义「物体表面很涩，不光滑；物体表面不平整不光滑」
