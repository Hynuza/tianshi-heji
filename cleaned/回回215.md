# 回回（215）

## 方志与著作记写

- 《小店方言研究》：写法「䞍等 / 停等」；释义「坐等（含贬义，批评）；坐享其成；呆着不动」
- 《太原方言词典》：写法「䞍等」；释义「❶坐等（批判、惩罚）：调皮捣蛋的，䞍等着挨屄斗❷坐享（现成的）：䞍等着吃现成，纯粹一个大小姐」
- 《晋语•应州方言例释》：写法「听（读如tìng）等」；释义「等待：知道你快回呀，娃娃就在街门口听等的哩。‖也作停等」
- 《应县方言词汇》：写法「庆、庆等 / 停等」；释义「等，等待。例看着捞上的几碗面，王桂桃经留小崔：你们欢欢吃哇，他不敢定多会儿回，再庆等，面就坨了；等候。例你甭停等啦，停等上半天也不顶」
- 《敖汉方言例释》：写法「䞍等着 / 䞍好儿」；释义「坐享其成或消极地等待。［举例1］再不想法儿，你就䞍等着受罪吧！［举例2］到时候，你就䞍等着吃香的喝辣的吧；告诉相关人员只管放心，坐等好的结果出现。［举例］这事儿你放心，就䞍好儿吧」
- 《元氏方言志》：写法「䞍等」；释义「等现成的」
- 《朝阳方言词语考释》：写法「‘䞍’，音qíng，在朝阳方言中表示‘等待接受某种后果’」
- 《关东方言词汇》：写法「䞍着 / 䞍等」；释义「等着；坐等；坐享」
