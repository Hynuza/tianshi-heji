## 方志与著作记写

- 《石楼方言词典》：写法「平不塌」；释义「①扁平。例：老和尚的帽子平不塌。②引申为人平庸。例：唩人没甚突出的地方，学习工作都是平不塌」
- 《太原方言点》：写法「平不塌」；释义「➊扁平：△和尚的帽子平不塌➋引申为人平庸：𠰻人学习工作都是平不塌」
- 《偏关方言》：写法「平不塌」；释义「扁平的样子◆火不好，馍馍蒸成些平不塌」
- 《晋语•应州方言例释》：写法「平不沓」；释义「没有突出之处：学习也就是个平不沓，指那不顶，由命去哇」
- 《大同方言博览》：写法「平不沓」；释义「不突出。歇后语有‘和尚的帽子——平不沓。’」
- 《大同方言词典》：写法「平不沓 / 平拓拓」；释义「形容事物状态平平，不突出。例歇后语：老道的帽子——平不沓；形容平坦之状。例：这块土地平拓拓的，望不到边」
- 《蒲县方言词汇选编》：写法「平不踏」；释义「指人的水平或业绩很平庸。例：别看他工作快三十年了，各方面都还是平不踏」
- 《阳城方言》：写法「平踏踏」；释义「形容很平。犹‘平展展’；平坦。例：大路铺得平踏踏，小路修得光鲇鲇」
- 《敖汉方言例释》：写法「歇后语‘老道的帽子——平遢遢’，意思是没什么业绩或成绩不突出」
- 《神木方言研究》：写法「平卜塌」；释义「形容扁平的样子：老和尚的帽子——平卜塌」
- 《陕北区域方言选释》：写法「板不塌 / 平忽塌 / 平普塌」；释义「扁平的样子：车上人多，挤的东挪不得西转，我袋子里的馍馍都压成些板不塌啦。也说‘板忽塌’；东西扁平；工作没起色；没上进心：那不愿意到这里工作，无奈来了应付了事，工作平忽塌，老百姓都有意见；①没有动静；没有开始：说修这段路啦，没动还是平普塌。②局面没有什么变化：人常说，新官上任三把火，可新书记上台以后，还是平普塌」
- 《蔚州方言词萃》：写法「平铺塌子」；释义「扁平；喻平庸，不突出。〔例〕这帽子是个平铺塌子，不好看。｜那人一辈子平铺塌子、漫不尖子的，没出了个色」
