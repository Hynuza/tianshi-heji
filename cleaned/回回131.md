## 方志与著作记写

- 《乡言研究》：写法「圆忒楞楞地 / 圆单单地」；释义「指形象，犹‘圆溜溜地’；指状态，犹‘圆满’：浑家偌圆单单地」
- 《晋语•应州方言例释》：写法「黑丹丹 / 圆蛋蛋」；释义「形容颜色很黑（含褒义）：这可好点儿黑布、洗完哩还黑丹丹的；形容很圆：头圆蛋蛋的」
- 《大同方言辞典》：写法「绵蛋蛋 / 圆蛋蛋」；释义「①形容食物吃进嘴里绵软、细腻的感觉。例如上乘的马铃薯和倭瓜。②形容人的皮肤、衣物或其它物体细腻、光滑、柔软的感觉；形容圆润的样子」
- 《晋蒙地带方言成语》：写法「圆圪蛋蛋」；释义「形容球体」
- 《陕北区域方言选释》：写法「脆嘚琅琅儿 / 明得郎朗 / 明圪丹丹儿 / 清得郎朗儿 / 清圪丹丹 / 圆格丹丹」；释义「指声音清脆：荨麻开花毛朵朵，脆嘚琅琅儿唱了一声想哥哥；形容明得发光：这铁壶擦得明得郎朗儿的；形容十分清楚的样子：会计的问题明圪丹丹儿价，就看你处理不处理；形容水清澈见底的样子；形容水清澈而明亮；特别圆：这娃娃头圆格丹丹的，可亲了」
- 《宣化方言》：写法「光旦旦 / 圆丢丢」；释义「非常光滑。/地面干净；滚圆的形状」
