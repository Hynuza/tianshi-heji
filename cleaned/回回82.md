# 回回（82）

来源文件: `[2025-07-19-0600]回回82.html`

## 方志与著作记写

- 《晋源方言》：写法「硬戳（ningcua）」；释义「形容人身体硬朗」
- 《偏关方言》：写法「硬强」；释义「老年人身体硬朗」
- 《灵丘县方言词语解读》：写法「牙爪」；释义「灵丘方言土语所说的‘牙爪’，完全是‘严厉’的意思。例如说，①那婆婆可牙爪着哩，把那媳妇们管得连大气也不敢出。②咋你这么牙爪，连颗瓜子儿也不叫俺们随便嗑」
- 《晋语•应州方言例释》：写法「硬（读如佞）强 / 硬（读如佞）扎无情」；释义「指身体硬朗：张志广甭看九十多岁了，身体可硬强哩，上街骑车子还耷楞楞的；不留情；强制进行：丹丹闹意见不回家，俺们众人硬扎无情地把她着（读如哲）回去了」
- 《大同方言博览》：写法「硬强」；释义「老年人身体健康。‘我妈九十岁啦，身体还挺硬强。’」
- 《阳城方言》：写法「硬强」；释义「①身体健壮；硬朗。例：老奶奶已经八十多岁了，身体还很硬强。②强硬。例：你那几句话说得够硬强，估计他不敢不听」
- 《内蒙古土默川方言赏析》：写法「硬强 / 硬铮 / 硬戳」；释义「形容老年人身体壮实健康。‘你爹现在身体怎么样？’‘挺硬强的，每年还种地了。’；老年人身体壮实健康。人家那身体可硬铮了，虽然六十多岁了，照样种地、喂牲口；办事果敢，有闯劲儿。出了门你要是不硬戳些，根本不行，有时候会让人欺负」
- 《旬阳方言词语》：写法「硬扎」；释义「①得力｜要完成这个任务，得给我抽两个硬扎人。②饭的质量高，即干而稠的饭｜今晚要夜战，下午得吃顿硬扎饭。③密度大、硬度高｜铁桨木最硬扎，适合做锄头把」
- 《海原方言词语汇释》：写法「硬扎」；释义「严格，严厉。人家话说得硬扎，我看不行了」
- 《兰州方言词典》：写法「硬扎」；释义「强硬：口气硬扎｜说话硬扎｜做事硬扎｜王厂长是个硬扎人，不好惹」
- 《陇右方言词语研究》：写法「硬扎」；释义「强硬。形容具有要挟性质或使人难受的状况。例一：今天的这北风硬扎得很，冻得人透心凉，刮得人站也站不住。例二：今天你去了对他们硬扎一点，不然他们又不当一回事。例三：刚才这个人口气硬扎得很，怕是上边来的」
