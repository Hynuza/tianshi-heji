# 乱乱（118）

来源文件: `[2024-05-01-0600]乱乱118.html`

## 方志与著作记写

- 《孝义俗语大观》：写法「肠子上咬人肚皮上挖」
- 《俗语解颐》：写法「债多不压人，虱多不咬人」；释义「发痒」
- 《汾阳方言研究》：写法「咬人」；释义「痒痒」
- 《汾阳话与普通话简编》：写法「咬 / 咬人咧 / 刺挠、刺咬人」；释义「痒，‘身上咬咧’；身上痒痒；发痒，‘衬衫不替洗，身上怪刺挠’」
- 《清徐方言研究》：写法「咬人」；释义「身上痒」
- 《交城方言研究》：写法「发痒人 / 发咬人」；释义「痒；痒」
- 《山西岚县方言》：写法「咬」；释义「痒：胳膊上咬得不能」
- 《宁武方言志》：写法「咬」；释义「痒」
- 《襄垣方言志》：写法「痒人」；释义「指皮肤发痒」
- 《浮山方言研究》：写法「咬人」；释义「虫把人叮得慌」
- 《秦州方言词语释义》：写法「肠子痒人搔不得 / 虱子多了不痒人」；释义「比喻因为某种特殊原因，难言之隐或难办之事，想说又不能说，想做又不能做。类似的有‘哑巴吃黄连，有理说不出’；形容头绪多、压力大，负担本身已经很重，再加一些也就不觉得了」
- 《韩城方言词语录（下册）》：写法「痒（发痒，土话叫咬，身上痒叫身上咬得很）」
- 《商州方言词汇研究》：写法「发咬人」；释义「人体比较敏感的地方，如腋窝，别人动时发痒、难受」
- 《陇西方言词语研究》：写法「肠子痒人——没处抓」
- 《品味延庆话》：写法「刺挠」；释义「即刺痒……延庆人称痒为‘咬’，口语化的刺痒为‘咬得慌’……‘咬’为痒的变音」
