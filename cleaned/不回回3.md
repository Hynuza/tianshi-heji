# 不回回（3）

来源文件: `[2025-10-30-0600]不回回3.html`

## 方志与著作记写

- 《胜溪俗语》：写法「不取贵」；释义「不自尊。〔例〕不用不取贵啦，撩逗的兀家做甚咧」
- 《俗语解颐》：写法「不取贵（不自尊）」
- 《偏关方言》：写法「取贵」；释义「值钱◆看也不能看？可把你取贵的」
- 《大同方言辞典》：写法「不为贵 / 不尊贵」；释义「价值低。引申为轻贱，人格低下。例：二欢子说，谁才那么不为贵，非要去他家吃那顿饭；不自尊，低俗」
- 《壶关方言词汇集》：写法「不取贵」；释义「指爱讨小便宜、不自尊、行为不检点：这人真不取贵，见甚往家取甚，谁家办事除喽吸喽㖸（nia）的烟，还把开了口的烟偷偷的就装了」
- 《陕北区域方言选释》：写法「不起苔」；释义「喻品质差；没志气；不起色，也没精神：死猫扶不上树，不起苔（抬）。也说‘不取贵’」
