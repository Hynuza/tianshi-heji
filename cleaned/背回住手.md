# 背回住手

## 方志与著作记写

- 《山西岚县方言》：写法「背抄手 / 叉起手来」；释义「背着手；双手交叉放在胸前」
- 《石楼方言词典》：写法「叉着胳膊」；释义「两手交叉在胸前」
- 《忻州方言词典》：写法「背抄 / 叉哩手」；释义「双手在背后相互握着：𠰻老汉在这儿背抄哩手站咾一会儿回去唡；叉着手儿（两手交叉在胸前）」
- 《五台方言研究》：写法「抄起手」；释义「两手一起放在背后」
- 《代县方言大全》：写法「背抄手」；释义「两手在背后相交」
- 《偏关方言》：写法「背抄手」；释义「双手反插在背后」
- 《晋语•应州方言例释》：写法「背抄手 / 抄手」；释义「双手放在背后交叉互握（有时兼有洋洋自得，与己无干之意）；两手互贴、互握或交叉：抄住手就那儿站的哩，一概不动」
- 《应县方言研究》：写法「抄手」；释义「两手在胸前交叉」
- 《应县方言词汇》：写法「背抄手 / 抄手」；释义「两个手搭在背后；与己无关的样子；两手在胸前交叉」
- 《朔州方言研究（右玉卷）》：写法「背抄手」；释义「背着手儿」
- 《永和方言研究》：写法「背捎起」；释义「背手」
- 《壶关方言词汇集》：写法「背抄手」；释义「双手在背后相互握着或交叉地放在背后」
- 《晋方言》：写法「操手」；释义「将两手对插袖筒内取暖」
- 《敖汉方言例释》：写法「抄手儿」；释义「双手交叉放在胸前或相对的袖子里，比喻对面临的问题袖手旁观。［举例］不管你咋忙，人家就抄手在那儿站着看热闹，啥也不干」
- 《西安方言词典》：写法「背抄着手 / 抄 / 抄着手」；释义「背着手儿，双手放在背后交叉握着；两手在胸前相互地插在袖筒里：抄着手；双手交叉伸到袖筒里：冷得人都抄着手」
- 《关中方言词语考释》：写法「两手从背后相搭叫‘背抄手’」
- 《府谷方言研究》：写法「背操」；释义「手臂放在身后。那老汉背操转手过来（口览）」
- 《宣化方言》：写法「背抄手 / 抄手」；释义「双手在背后互相抓着；两手互相插进对方的袖筒里温暖双手」
