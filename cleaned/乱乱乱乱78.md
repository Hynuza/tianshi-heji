# 乱乱乱乱（78）

来源文件: `[2024-09-07-0600]乱乱乱乱78.html`

## 方志与著作记写

- 《汾阳方言研究》：写法「死蔫 / 死蔫半垂 / 死蔫兀烂」；释义「没精打采的样子；有气无力、无精打采、慢吞吞的样子，带贬义；有气无力、无精打采、慢吞吞的样子，带贬义」
- 《太原方言词典》：写法「伍烂」；释义「形容词后缀，表示程度，含厌恶意：黑死伍烂（颜色暗淡显得陈旧）」
- 《盂县方言词汇》：写法「死蔫圪朽」；释义「生长缓慢，朽缩：萝卜死蔫圪朽的长得不旺。蔫，读烟」
- 《忻州方言词典》：写法「死秧子」；释义「比喻死气沉沉的人」
- 《应县方言词汇》：写法「死秧子」；释义「没生气的人。例一个死秧子货，我没在，你过不能给开开门」
- 《阳城方言》：写法「死恹不烂」；释义「半死不活的样子：这头猪得病了，死恹不烂的已经半个月了」
- 《陕北区域方言选释》：写法「死蔫乌烂 / 死延格蠕」；释义「慢慢腾腾；拖拖拉拉：做上生活死蔫乌烂，像个什么；没有阳刚之气；没精神：年轻人要拿起精神工作啦，不能死延格蠕，说一句动一下。也作‘死焉各处’、‘死烟各处’」
- 《神木方言研究》：写法「死蔫」；释义「蔫：死蔫黄瓜」
- 《关东方言词汇》：写法「死殃巴出」；释义「不爱说话，不与他人交往」
