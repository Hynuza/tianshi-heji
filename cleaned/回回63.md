## 方志与著作记写

- 《孝义方言志》：写法「风窟联 / 雨窟联」；释义「月亮周围有缺口的云圈，是晴天的前兆；月亮周围无缺口的云圈，是雨天的前兆」
- 《乡言研究》：写法「骨碌子」；释义「套包」
- 《汾阳话与普通话简编》：写法「咯挛儿 / 咯芦则 / 咯卷则 / 车毂辘」；释义「烤制的环状面食干粮；水或尿在布或纸上留下痕迹；牲口脖子上套的卷子；车轮套在轴上的部分」
- 《平遥方言民俗语汇》：写法「括拦 / 日括连 / 月括连 / 风括连 / 雨刮连」；释义「为小孩过生日蒸的圆圈状的面食品。‘括拦’可能是‘圈’的分音词；日晕。‘括连’是‘圈’的分音词。指太阳四周的光圈。‘日括连’是变天气的先兆；月晕。指月亮四周的光圈；月亮四周封口的光圈，刮风的先兆；月亮四周的不封口的光圈，下雨的先兆」
- 《晋源方言》：写法「跳窟鸾」；释义「跳圈圈」
- 《平定话》：写法「壳拉」；释义「圆圈。如说‘转了个壳拉儿’。也代指圆形物」
- 《繁峙方言俗语汇编》：写法「一步近，两步远，三步绕个大圐圙」
- 《应县方言词汇》：写法「圐略」；释义「弯曲。例你圐略住腿，上炕哇」
- 《霍州方言研究》：写法「风箍连」；释义「风雨要来的预兆」
- 《壶关方言词汇集》：写法「圪练 / 圪联的」；释义「圐圙。用围墙围起来的空地；圆圈：画喽个圪联的」
- 《府谷方言研究》：写法「括联」；释义「圈的分音词，名词。月儿爷爷戴了个大括联，明儿刮风呀。/拜年不拜年，先尝你家糕括联子甜不甜。［糕括联为一种油炸食物，圆圈形］」
- 《神木方言研究》：写法「骨联住睡」；释义「曲腿侧睡」
