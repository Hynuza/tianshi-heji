# 回回（24）

来源文件: `[2024-12-26-0600]回回24.html`

## 方志与著作记写

- 《平定方言研究》：写法「捞煞 / 正瞭色嘞，看见你来啦（正四下里看呢，远远得看见你来了。） / 四下里瞭色瞭色（到处看看）」；释义「四处张望」
- 《平定话》：写法「瞭洒 / 䁖色」；释义「向外观望或登高远望。如说：‘大妈到街门口瞭洒了好几回，闺女女婿说好今天要来看她的。’；瞅瞅，看看。䁖」
- 《盂县方言词汇》：写法「东老西射 / 老射」；释义「向左右前后看：你东老西射地看什么哩；用游移的目光四处看：老射了半天也没看到你」
- 《忻州方言词典》：写法「老煞」；释义「四处查看寻找：你老煞甚哩？|一边走一边老煞看有卖韭菜哩呀没裸（没有）」
- 《宁武方言志》：写法「老煞」；释义「四处张望」
- 《代县方言大全》：写法「捞脎」；释义「四处查看。例：我捞脎了半天也没看到他的影子」
- 《朔县方言志》：写法「老煞」；释义「张望、寻找：我老煞咾半天也没寻见」
- 《偏关方言》：写法「老沙 / 睄瞭」；释义「观察找寻◆你老沙甚咧；观望◆我出门去呀，你给我睄瞭家的」
- 《山阴方言研究》：写法「老色」；释义「东瞅瞅西瞧瞧（找东西）老色针跌到哪子去了」
- 《平鲁方言志》：写法「老色」；释义「寻找」
- 《应县方言词汇》：写法「老煞」；释义「张望。例老煞了半天，也没见，是不是还没出来呢」
- 《晋语•应州方言例释》：写法「不拉色」；释义「不留意：甲：你没见明明？乙：啊呀，不拉色，没见过这儿」
- 《晋蒙地带方言成语》：写法「东老西挲」；释义「向东瞭瞭，向西看看，形容四处张望、寻找。‘老挲’可能是‘瞭哨’的变音」
- 《神木方言研究》：写法「瞭哨」；释义「①望；②望风；③探望」
- 《元氏方言志》：写法「劳撒」；释义「瞥；瞟；留心看：我劳撒咾他一眼」
- 《凉州方言词语考释》：写法「睩睃」
