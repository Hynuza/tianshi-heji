# 回回（93）

来源文件: `[2025-08-19-0600]回回93.html`

## 方志与著作记写

- 《汾阳方言研究》：写法「凑势 / 凑势/就势」；释义「顺势；义为‘顺势’，顺便做某事，例如：（10）你回喽凑势/就势把这些儿菜给你妈带回去吧。（11）你凑势/就势告给他不用过来啦」
- 《汾阳话与普通话简编》：写法「就势儿」；释义「就手儿」
- 《平遥方言民俗语汇》：写法「就手儿」；释义「马上、立刻。如：一问你不在，人家就手儿就走了」
- 《太原方言词典》：写法「就手」；释义「顺手：出去就手带上门」
- 《偏关方言》：写法「跟手儿」；释义「随手」
- 《大同方言辞典》：写法「凑手 / 就手儿」；释义「手里的钱物方便赶趟；就便，随手」
- 《卧虎山麓方言》：写法「凑手」；释义「顺便」
- 《沁河流域民俗语汇：以端氏方言为例》：写法「凑手」；释义「顺手」
- 《上党地区方言研究（阳城卷）》：写法「凑手 / 就手」；释义「顺手；相当于‘顺手、顺便’，表示做完某事顺便做另外一件事」
- 《敖汉方言例释》：写法「不凑手 / 就捎 / 就手儿」；释义「眼下能够支配的钱或物不足，不能应对面临的问题。［举例］我这两天钱有点儿不凑手，你再缓几天；顺便。［举例］你上供销社就捎给我邮封信；顺便，捎带着。［举例］你上班就手儿把垃圾倒了」
- 《内蒙古土默川方言赏》：写法「就连儿」；释义「①表示一个行为顺着前一个行为而发生，大致相当于‘顺便’、‘一起’、‘一并’等等意思。你去超市买面，就连儿再买上一桶油哇。你买票时就连儿给我也买一张。②表示后面的动作行为与前面的动作行为衔接紧密，连续发生。相当于‘紧接着’、‘立马’。她一听这个消息，就连儿昏过去了。他们吃完饭就连儿把账结了」
- 《宣化方言》：写法「不凑手」；释义「急用财物而不够」
- 《元氏方言志》：写法「就手儿」；释义「紧接着；马上：他吃咾饭，就手儿都刷咾碗兰」
