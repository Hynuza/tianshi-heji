# 回（49）

## 方志与著作记写

- 《汾阳话与普通话简编》：写法「概 / 概共」；释义「常久，‘概不下雨’；绝对，‘概不能’，‘概不是’；向来，‘概共不来’」
- 《平遥方言民俗语汇》：写法「概」；释义「总。如：兀些人概不想动弹，是圪截狗游吊子」
- 《交城方言研究》：写法「概」；释义「‘从来’、‘永远’的意思。如‘概不来’是‘从来不来’的意思；‘概不见’是‘总也不见’的意思」
- 《文水方言志》：写法「概」；释义「再，如：走了概没来过」
- 《太原方言词典》：写法「概」；释义「一概：干咾这来多年，概也没出过事儿」
- 《偏关方言》：写法「概共 / 海共」；释义「向来◆我们概共也没来往；总共◆海共也没来了多少人」
- 《应县方言词汇》：写法「概」；释义「从来，一直。例一只母鸡气得发脾气：他们搞计划生育哩，可硬叫我下蛋呢。一头牛说，你那算啥？他们天天喝我的奶概黑不叫我妈哩」
- 《应县方言研究》：写法「概 / 自打任书记退了，概没见他来过」；释义「好久；自打任书记退了，好久没见他来过」
- 《晋语•应州方言例释》：写法「概 / 概共」；释义「经常；一直：单位塌炉了，就等破产的哩，概也用不着去；总是；从来：小禹概共也没骑过自行车，在街上看见从来是步走。‖也说概总」
- 《天镇方言研究》：写法「概」；释义「相当于普通话的‘一概’，表示全部，也表示累计范围之内从来都是等意义。如：（10）他自从走了以后，概没来过我家。（11）他中午概吃的是一个馒头」
- 《内蒙古土默川方言赏析》：写法「概 / 概共」；释义「表示从过去一直到现在这段时间，含有强调语气，常常跟‘也’、‘也不’、‘不’配合，大致相当于‘从来’、‘向来’。你概也不来我们这儿，这回多住几天哇；表示从过去一直到现在这段时间，含有强调语气，常常跟‘也’、‘也不’、‘不’配合，大致相当于‘从来’、‘向来’。他概共也没有迟到过，这可是头一回。他概共没进过城，看见什么都稀罕」
- 《蔚州方言词萃》：写法「概」；释义「副词，表示‘一直’、‘很长时间’。比‘永’语意略轻，如说‘概也不来’，不等于他连一次也不来，而是偶而也来一回，只是很少来罢了」
