# 回人

来源文件: `[2024-11-18-0600]回人.html`

## 方志与著作记写

- 《胜溪俗语》：写法「为人一条路，惹人一堵墙」
- 《孝义俗语大观》：写法「急为人」；释义「临时拉拢别人」
- 《汾阳方言研究》：写法「为朋友处弟兄」
- 《忻州方言词典》：写法「为人」；释义「会处人：𠰻后生可为人哩，不愁娶个媳妇儿」
- 《忻州谚语词典》：写法「打高墙，喂恶狗，不如四海维朋友」；释义「团结」
- 《繁峙方言俗语汇编》：写法「维人」；释义「①动词，讨别人的喜欢，让别人说好。如：他经常拿集体的钱财去维人。②名词，很善于处理好和别人的关系。如：他平时维人，关键时刻，别人都为他说好话」
- 《应县方言词语》：写法「水太清养不住鱼，人太精维不下友」
- 《晋语•应州方言例释》：写法「维人 / 维朋友结弟兄」；释义「人缘好；善于团结人：刘大爷挺维人，周围人没人说赖；广交朋友（含贬义）：一天就那维朋友结弟兄的，把两（轻声）个钱全花得那儿啦，一概不管家」
- 《卧虎山麓方言》：写法「不为（二声）人」；释义「不团结人，例：他平时不为人」
- 《阳城方言》：写法「维人」；释义「指笼络人心，维护人际关系。例：维人一条路，惹人一堵墙。｜不会维人，寸步难行」
- 《内蒙古土默川方言赏析》：写法「维 / 维人」；释义「结交。他没有维下几个朋友；容易与人相处；善于团结人。维，结交。那后生可维人了，走到哪，身边都有一大帮朋友」
- 《敖汉方言例释》：写法「咱也拉个主动，省的以后遇到事儿了再围人不赶趟 / 围人儿」；释义「有意结交朋友为自己所用。［举例］看你小李多会围人儿啊」
- 《关中方言词语汇释》：写法「为」；释义「结交。如说‘人一生一定要为几个知心朋友’。李劼人」
- 《银川方言词典》：写法「维」；释义「结交：△打高墙，喂好狗，不如跑着维朋友｜△维下蒙古人有马骑，维下找脖子（指山西人）活剥皮」
- 《永登及周边方言词语汇释》：写法「维人」；释义「活人，与人发展和保持良好关系，维下某人即与某人交好」
- 《陇西方言词语研究》：写法「维人不嫌人，嫌人不维人 / 维人要维真君子，惹人不要惹小人 / 天晴修水路，无事维朋友」；释义「结交；交朋友」
- 《西宁方言词典》：写法「维」；释义「交友并长期保持其关系：家是我新维下的朋友｜一辈子一个人啊没维下，死了没人抬」
- 《品味延庆话》：写法「好维」；释义「指人的脾气秉性好，容易结交。如，‘你不了解他，其实这个人挺好维的。’‘维’应是沟通、维系之意」
- 《四川方言词语汇编》：写法「维」；释义「结交。例：那么多的人都维得完么」
